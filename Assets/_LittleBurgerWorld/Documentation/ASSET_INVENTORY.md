# Asset Inventory

Every asset is **original** and generated by code in `Scripts/Editor` (re-running Setup reproduces it exactly), except the font. No McDonald's (or any other) branding, characters, packaging or designs are used; the fries box uses a red box with a yellow star badge, the sign and logo are our own.

## Recommended replacements before commercial release
1. Professionally modelled & rigged animals (keep the `ProceduralCharacterRig` interface or swap to an Animator with the same pose names).
2. Sculpted food models with baked AO (keep pivots at the bottom and `stackHeight`).
3. Optional: replace the AI voice with a recorded child-friendly voice actor (same file names).
4. Illustrated UI icon set in the same style.


**Thai font:** `Art/UI/Fonts/Mitr-Medium.ttf` (Cadson Demak, SIL Open Font License 1.1, licence in `Mitr-OFL.txt`) – used automatically as Fredoka's fallback for Thai characters.

**Replay content:** egg / onion / ketchup / mustard prefabs, ice cream cart and cone, 20 toy illustrations, washing-up and capsule UI art, theme decorations (balloons, cake, rain, fairy lights) – all generated by `PrefabBuilder`, `IconLibrary.Toys` and `SceneBuilder.BuildThemes`.
