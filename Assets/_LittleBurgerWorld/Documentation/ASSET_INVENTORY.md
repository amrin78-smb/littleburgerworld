# Asset Inventory

Every asset is **original** and generated by code in `Scripts/Editor` (re-running Setup reproduces it exactly), except the font. No McDonald's (or any other) branding, characters, packaging or designs are used; the fries box uses a red box with a yellow star badge, the sign and logo are our own.

| Category | Assets | Source | Status |
|---|---|---|---|
| Font | `Art/UI/Fonts/Fredoka-SemiBold.ttf` | Google Fonts "Fredoka", SIL Open Font License (`OFL.txt` alongside), static SemiBold instance created with fontTools | Final |
| Icons & UI sprites | ~45 PNGs in `Art/UI/Icons` (ingredients, burgers, fries, milkshakes, meal, portraits, home/play/star/heart/hand/gear/etc., panels, bubble) | `IconLibrary` (SDF painter) | Final for prototype; could be replaced by illustrator art |
| Stickers | 9 sticker PNGs | `IconLibrary` | Final for prototype |
| Textures | Floor checker, wall polka dots, app icon | `IconLibrary` | Final for prototype |
| Meshes | Rounded boxes, buns, patty, lettuce frill, tomato, seeds, cups, cream swirl, baskets, lamp, pot, etc. (`Art/Meshes`) | `MeshFactory` via `ArtLibrary` | Procedural; **replace with modelled versions for a commercial release** (see below) |
| Materials | ~60 URP Lit pastel materials + 6 FX materials | `ArtLibrary` | Final |
| Food prefabs | 7 ingredients (incl. unlockable pickles), potato, fries batch, fries box, milkshake cup | `PrefabBuilder.Food` | Procedural |

## Recommended replacements before commercial release
1. Professionally modelled & rigged Benny/Penny (keep the `ProceduralCharacterRig` interface or swap to an Animator with the same pose names).
2. Sculpted food models with baked AO (keep pivots at the bottom and `stackHeight`).
3. Recorded child-friendly voice lines for every key in the AudioLibrary.
4. Illustrated UI icon set in the same style.
