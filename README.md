# Little Burger World

A toddler-friendly (ages 2–7) 3D toy burger restaurant for Android, made with **Unity 6000.3 + URP**.
Make burgers, fries and milkshakes and serve Benny the Bear. No timers, no failure, no ads, no purchases, fully offline.

* **LET'S PLAY!** – six picture-guided activities with a helper hand that never lets a child get stuck.
* **FREE PLAY** – everything at once, any order, customers keep coming and love whatever they get.

## Quick start
1. Open the folder in Unity Hub (Unity **6000.3.27f2** with Android Build Support).
2. Open `Assets/_LittleBurgerWorld/Scenes/Boot.unity` → Play.
3. Android: **Little Burger World ▸ Build Android APK** → `Builds/Android/LittleBurgerWorld.apk` (ARMv7 + ARM64; PowerVR GPUs use OpenGL ES 3).

All art, audio, prefabs, data and scenes are generated by **Little Burger World ▸ Setup Project** (re-runnable).
